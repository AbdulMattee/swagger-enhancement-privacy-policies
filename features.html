Complete Features Guide & Usage Instructions

Welcome to Swagger UI Enhancement!

This Chrome Extension supercharges your Swagger UI experience with powerful features designed to boost productivity for API developers, testers, and technical teams. Below you'll find detailed explanations of each feature and step-by-step instructions on how to use them.

Token Management

Save, manage, and auto-inject JWT/Bearer tokens

What is this feature?

The Token Management system allows you to save multiple authentication tokens (JWT, Bearer, etc.) with custom names and switch between them instantly. When you select a token, it's automatically injected into all your API requests, eliminating the need to manually copy-paste tokens into Swagger's authorization modal.

Why you need it: Stop wasting time copying tokens between different environments (dev, staging, production) or user roles. One click switches your entire authentication context.

📖 How to Use

  1. Add a Token: Click the ➕ button in the token panel at the top of the page
  2. Name Your Token: Enter a descriptive name (e.g., "Production Admin", "Dev User", "Staging API")
  3. Paste Token Value: Enter your JWT or Bearer token (the extension accepts any format)
  4. Save: Click "Add Token" - the token is saved and automatically activated
  5. Switch Tokens: Use the dropdown menu to select different tokens instantly
  6. Copy Token: Click the 📋 button to copy the active token to your clipboard
  7. Manage Tokens: Click the ⚙️ button to view all saved tokens, update them, or delete them

💡 Pro Tips

  • The active token is displayed prominently in red text for easy identification
  • Tokens are automatically injected into ALL API requests (both Swagger UI and manual fetch/XHR calls)
  • Your tokens are stored securely in your browser's local storage - never transmitted externally
  • You can have unlimited tokens saved for different environments and users

API Search Sidebar

Lightning-fast search across all API endpoints

What is this feature?

The API Search Sidebar provides instant search across all available API endpoints. Search by HTTP method (GET, POST, etc.), path, description, or tag. Navigate results with your keyboard and jump directly to any endpoint with smooth scrolling and highlighting.

Why you need it: In large API documentation with hundreds of endpoints, finding a specific API manually is time-consuming. This feature lets you find any endpoint in seconds.

📖 How to Use

  1. Open Sidebar: Click the burger menu button (☰) in the top-left corner
  2. Start Typing: Enter your search query - it searches across methods, paths, descriptions, and tags
  3. Navigate Results: Use ↑ and ↓ arrow keys to move through results
  4. Select Endpoint: Press Enter to jump to the highlighted endpoint
  5. Close Sidebar: Press Esc or click the ✕ button

⌨️ Keyboard Shortcuts

Cmd+K (macOS) or Ctrl+K (Windows/Linux) - Toggle sidebar
↑ ↓ Navigate results
Enter Select endpoint
Esc Close sidebar

💡 Pro Tips

  • Search is real-time - results update as you type
  • Search is case-insensitive for convenience
  • Selected endpoints are highlighted with an animation for easy identification
  • The sidebar remembers your last search query during the session

Table of Contents (TOC)

Fixed navigation panel for quick API overview

What is this feature?

The Table of Contents displays all API tag sections in a fixed left sidebar. It provides a bird's-eye view of your API documentation and allows instant navigation to any section. The TOC is fully customizable - resize it, collapse it, or configure it to close automatically after clicking.

Why you need it: Large API docs are hard to navigate. The TOC gives you a persistent overview and one-click access to any section, no matter where you are on the page.

📖 How to Use

  1. View TOC: The TOC appears automatically on the left side if your API has tag sections
  2. Navigate: Click any tag name to jump to that section instantly
  3. Collapse/Expand: Click the toggle button (◀/▶) or use the keyboard shortcut
  4. Resize Width: Drag the right edge of the TOC to adjust its width
  5. Reset Width: Double-click the resize handle to reset to auto-calculated width
  6. Configure Behavior: In the settings menu (⚙️), toggle "Close TOC on click" to auto-collapse after navigation

⌨️ Keyboard Shortcuts

Cmd+J (macOS) or Ctrl+J (Windows/Linux) - Toggle TOC

💡 Pro Tips

  • Your TOC width and collapsed state are saved automatically
  • The TOC intelligently adjusts its width to avoid overlapping content
  • Enable "Close on click" in settings for a minimalist workflow
  • The TOC only appears if your API documentation has tag sections

Favorite APIs (Quick Access Pills)

Bookmark frequently-used endpoints for instant access

What is this feature?

Mark any API endpoint as a favorite by clicking the star icon next to it. Your favorite APIs appear as clickable "pills" at the top of the page, providing one-click access to your most-used endpoints. The system intelligently removes common path prefixes for cleaner display.

Why you need it: Most developers work with a subset of APIs repeatedly. Favorites let you skip the search and jump directly to the endpoints you use most.

📖 How to Use

  1. Add Favorite: Click the ⭐ star icon next to any API endpoint
  2. View Favorites: Your favorite APIs appear as pills in the "Favorite APIs" section at the top
  3. Navigate: Click any pill to instantly jump to that endpoint
  4. Remove Favorite: Click the × button on a pill, or click the star icon again on the endpoint
  5. Configure Sticky: In settings (⚙️), toggle sticky behavior for the favorites section

💡 Pro Tips

  • Pills are color-coded by HTTP method (GET, POST, PUT, DELETE, etc.)
  • Common path prefixes (like /api/v1) are automatically removed for cleaner display
  • Long paths are intelligently truncated to show the most relevant parts
  • Favorites persist across browser sessions and page refreshes
  • The favorites section can be sticky (scrolls with you) - toggle in settings

Request Body Persistence

Save and load request body templates

What is this feature?

For POST, PUT, PATCH, and DELETE endpoints, the extension adds three action buttons: Save, Load, and Format. Save your request bodies as templates and reload them instantly. The Format button pretty-prints your JSON for better readability and helps catch syntax errors.

Why you need it: Stop re-typing the same request bodies over and over. Save them once and reload them whenever needed. The format button ensures your JSON is valid before sending.

📖 How to Use

  1. Expand Endpoint: Click on any POST, PUT, PATCH, or DELETE endpoint to expand it
  2. Find Buttons: Look for the "Quick Actions" section with three buttons
  3. Save Body: Enter your request body, then click the 💾 Save button
  4. Load Body: Click the 📂 Load button to retrieve your saved body
  5. Format JSON: Click the ✨ Format button to pretty-print and validate your JSON

💡 Pro Tips

  • Each endpoint has its own saved body - they don't interfere with each other
  • The Format button validates JSON and shows an error if it's malformed
  • Saved bodies persist across page refreshes and browser sessions
  • GET endpoints don't show these buttons (they don't have request bodies)
  • Bodies are stored in your browser's local storage - never sent externally

Settings & Customization

Personalize your experience

What is this feature?

The settings panel lets you customize the extension's behavior to match your workflow. Toggle sticky positioning for the token panel and favorites, configure TOC behavior, manage your saved tokens, and restart the interactive tour.

Why you need it: Everyone works differently. Settings let you tailor the extension to your preferences.

📖 How to Use

  1. Open Settings: Click the ⚙️ gear icon in the token panel
  2. Manage Tokens: View all saved tokens, activate/deactivate them, update values, or delete them
  3. Toggle Sticky Token Panel: Enable/disable sticky positioning for the token panel
  4. Toggle Sticky Favorites: Enable/disable sticky positioning for favorite APIs
  5. Configure TOC: Enable "Close TOC on click" to auto-collapse after navigation
  6. Restart Tour: Click "Restart Tour" to see the interactive walkthrough again

💡 Pro Tips

  • All settings are saved automatically and persist across sessions
  • Sticky positioning keeps UI elements visible while scrolling
  • You can update token values without deleting and re-adding them
  • The tour is a great way to rediscover features you might have forgotten

Interactive First-Time Tour

Guided walkthrough of all features

What is this feature?

When you first use the extension, an interactive tour guides you through all features with step-by-step instructions and visual highlights. The tour intelligently adapts to your API documentation and can be restarted anytime from settings.

Why you need it: Discover all features without reading documentation. The tour shows you exactly where everything is and how to use it.

📖 How to Use

  1. First Visit: The tour starts automatically on your first visit to a Swagger page
  2. Navigate Tour: Click "Next" to move forward, "Previous" to go back
  3. Skip Tour: Click "Skip Tour" if you want to explore on your own
  4. Restart Tour: Open settings (⚙️) and click "Restart Tour" to see it again

💡 Pro Tips

  • The tour locks scrolling to prevent confusion - you can't accidentally navigate away
  • Each step highlights the relevant UI element with animations
  • The tour adapts to your API - it finds the best example endpoints to demonstrate
  • You can restart the tour anytime to refresh your memory

Installation & Activation

Get started in minutes

How to Install

The extension can be loaded directly into Chrome for immediate use. It automatically activates on common Swagger UI URLs, with manual activation available for custom domains.

💡 Pro Tips

  • Manual activation is "sticky" - once enabled for a domain, it auto-loads on future visits
  • The extension works on localhost and remote servers
  • All your data (tokens, favorites, settings) is stored locally in your browser
  • No internet connection required after initial Font Awesome icon load

Need Help?

For issues, questions, or feature requests, please refer to the extension documentation.

Privacy: This extension stores all data locally in your browser. No data is transmitted to external servers.
